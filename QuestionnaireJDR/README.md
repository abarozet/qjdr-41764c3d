# Questionnaire JDR — Installation

Cette application lit les réponses du formulaire Google
« Questionnaire sur les profils-types de joueurs » et crée un rapport
pour chaque joueur, ainsi qu'un rapport global.

Rien à installer : il suffit d'un navigateur internet
(Edge, Chrome, Firefox ou Safari). Les réponses restent sur votre
ordinateur : rien n'est envoyé sur internet.


## Sur un ordinateur Windows

1. Enregistrez le fichier `QuestionnaireJDR.zip` (par exemple dans
   « Documents »).
2. Faites un clic droit sur `QuestionnaireJDR.zip`, puis choisissez
   **Extraire tout…**, puis **Extraire**.
   Un dossier `QuestionnaireJDR` apparaît.
3. Ouvrez ce dossier et double-cliquez sur **`Questionnaire JDR.html`**.
   L'application s'ouvre dans votre navigateur.

> ⚠️ Important : extrayez bien le fichier .zip d'abord.
> Si vous double-cliquez sur `Questionnaire JDR.html` directement
> dans le .zip, l'application ne fonctionnera pas.

Astuce : pour la retrouver facilement, faites un clic droit sur
`Questionnaire JDR.html` → **Envoyer vers** → **Bureau (créer un raccourci)**.


## Sur un Mac

1. Double-cliquez sur `QuestionnaireJDR.zip` : un dossier
   `QuestionnaireJDR` apparaît à côté.
2. Ouvrez ce dossier et double-cliquez sur **`Questionnaire JDR.html`**.

Conseil : avec Chrome ou Edge, vous pourrez enregistrer vos
modifications de configuration directement dans le dossier.
Avec Safari ou Firefox, elles sont enregistrées sous forme de fichier
`configuration.zip` à télécharger.


## Sur une tablette ou un téléphone (Android, iPad)

Le fichier .zip ne fonctionne pas sur tablette.
Utilisez plutôt le **lien** de l'application qui vous a été envoyé :
ouvrez-le dans Chrome (ou Safari sur iPad), puis choisissez
**Ajouter à l'écran d'accueil**.


## Et ensuite ?

Une fois l'application ouverte, cliquez sur l'onglet **Aide** :
le guide explique pas à pas comment charger les réponses,
lire les rapports et modifier la configuration.

Pour essayer tout de suite : onglet **Données** → **Charger l'exemple**.


## Contenu du dossier

| Élément | À quoi ça sert |
|---|---|
| `Questionnaire JDR.html` | L'application : c'est le fichier à ouvrir. |
| `configuration/` | Les questions, les points et les textes des rapports. |
| `documentation/` | Le guide d'utilisation (aussi visible dans l'onglet Aide). |
| `exemples/` | Un fichier de réponses fictives pour essayer. |
| `app/` | Le fonctionnement interne — ne pas modifier. |
